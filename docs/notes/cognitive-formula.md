# AI 时代学习认知公式

```
R = B × (A + V) × (M × C) × E

R  = 认知产出 (Result)
B  = 广度 (Breadth) — 跨领域知识的覆盖面
A  = 抽象 (Abstraction) — 提取问题本质结构的速度
V  = 跳跃 (Leap) — 源域→目标域跨域映射的跨度
M  = 模型推演 (Model) — LLM/系统的推理验证能力
C  = 自纠正 (Correction) — 反馈闭环的强度
E  = 吸收效率 (Efficiency) — 新知识固化为认知索引的速率
```

### 乘法架构

任一因子为 0 → 整个公式为 0。碎片单独存在没有意义，乘法合成才是完整认知单元。

### Praxis Agent OS 映射
